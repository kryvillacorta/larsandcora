This is **not** the Next.js version in your training data. APIs, conventions, and file structure may differ. Notable differences active in this project:

- Tailwind is imported via `@import "tailwindcss"` in `globals.css`, not `@tailwind` directives.

## Architecture

Single-page marketing site using the **App Router**. All content lives on one scrollable page (`src/app/page.tsx`) composed of section components.

**Routing:** `src/app/` — only the root route exists. No dynamic routes, API routes, or nested layouts yet.

**Components:** `src/components/` — one file per page section, rendered in order by `page.tsx`:
`Nav → Hero → Details → OurStory → Schedule → Travel → Registry → RSVP → Footer`

Client components (`"use client"`) are only `Nav` (scroll listener) and `RSVP` (form state). Everything else is a server component.

## Styling

**Fonts:** `Cormorant_Garamond` (body/labels, `--font-cormorant`) and `Playfair_Display` (headings/display, `--font-playfair`), loaded via `next/font/google` in `layout.tsx`. Apply them with Tailwind's arbitrary value syntax: `font-[family-name:var(--font-cormorant)]`.

**Color palette** (defined as CSS custom properties in `globals.css`, not Tailwind config):
- `#fdf8f3` cream background
- `#2c2c2c` dark text
- `#c4847a` dusty rose (primary accent, CTAs, hover states)
- `#e8c4b4` blush (borders, dividers)
- `#8a9e8a` sage (secondary labels, uppercase tracking text)
- `#7a7a6e` muted (body copy, captions)

All colors are used inline as Tailwind arbitrary values (`text-[#c4847a]`), not as named theme tokens.

**`.section-divider`** is a utility class in `globals.css` that renders a centered text element flanked by `#e8c4b4` horizontal rules.

## RSVP Form

The RSVP component has a stub submission handler (`setTimeout` mock). To wire it to a real backend, replace the `handleSubmit` body in `src/components/RSVP.tsx`. Conditional fields (guest count, meal preference) render only when `attending === "yes"`.
