## Architecture

Single-page wedding invitation site (Larwyn & Cora, Jan 31, 2027) using the **App Router**. All content lives on one scrollable page (`src/app/page.tsx`) composed of section components.

**Routing:** `src/app/` has the root route and one API route, `src/app/api/rsvp/route.ts` (see RSVP Form). No dynamic routes or nested layouts.

**Components:** `src/components/` — one file per section plus a co-located `*.module.css`, rendered in order by `page.tsx`:
`ScrollReveal` (behavior only) `→ Nav → Hero → Invitation → Verse → Entourage → DressCode → GiftGuide → BeforeRsvp → Closing`

`BeforeRsvp` embeds `RsvpForm`. Client components (`"use client"`): `Nav` (scroll/mobile menu), `DressCode` (tabs), `ScrollReveal` (fade-in), `RsvpForm` (form state). Everything else is a server component.

## Styling

**Approach:** CSS Modules per component (`Component.module.css`) plus shared classes in `src/app/globals.css` (`.section`, `.section-navy`, `.section-title`, `.lead`, ...). Tailwind is loaded (`@import "tailwindcss"`) but the site is mostly hand-written CSS.

**Fonts** (`layout.tsx`): local fonts in `src/fonts/` — `Anaktoria` (headings, `--font-heading`) and `Cooper Lt BT Light` (body, `--font-body`) via `next/font/local`; `Cormorant_Garamond` italic (`--font-script`) via `next/font/google` as a stand-in for the couple's name lettering until the final script font is added.

**Color palette** (CSS custom properties in `globals.css`): `--navy #1f3350` (text, dark sections), `--sky #b8d7ea` (text on navy), `--cream #fffdf0` (background), `--paper #faf8f4`, plus `--placeholder` / `--placeholder-text` for image placeholders. Images live in `public/images/`.

## RSVP Form

`src/components/RsvpForm.tsx` posts `{ name, attending, website }` to `src/app/api/rsvp/route.ts`, which forwards it to a Google Apps Script web app that appends a row to a Google Sheet. Needs `RSVP_SHEET_URL` and `RSVP_SHEET_SECRET` (in `.env.local` locally, in Vercel project env vars when deployed). Setup steps: `docs/rsvp-google-sheets.md`. The route has a honeypot field (`website`) and an in-memory rate limit (5 per IP per 10 min).
